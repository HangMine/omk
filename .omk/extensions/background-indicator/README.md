# 백그라운드 실행 표시

이 체크아웃에서 OMK를 시작하면 자동 로드되는 프로젝트 확장입니다.

입력창 위와 상태줄에 실행 중 개수, 작업명, ID, 경과 시간을 표시합니다. 1초마다 기존 `pi-background-tasks`의 읽기 전용 상태 API를 조회하며, 직접 프로세스를 실행하거나 종료하지 않습니다. 최대 3개 작업과 추가 개수를 표시하고 종료된 작업은 제거합니다. 서비스 오류/응답 시간 초과 때는 오래된 실행 표시를 지웁니다.

```text
▶ 백그라운드 실행 중 1개
  장기 안정성 검사 [b865a7919] 6분 12초
```

`pi-background-tasks` v1 EventBus API가 필요합니다. 패키지가 없거나 RPC/headless 모드이면 표시하지 않습니다. 위젯은 기존 OMK Text 렌더러가 좁은 폭에 맞춰 줄바꿈합니다.

새 OMK 활성화부터 반영됩니다. 이미 진행 중인 백그라운드 작업을 보존하기 위해 강제 `/reload`하지 마세요. 현재 세션에서는 기존 `/bg` 명령으로 작업 목록을 볼 수 있습니다. 기존 registry, 알림과 완료 후 자동 후속 실행은 변경하지 않습니다.
