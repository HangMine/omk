## 변경 파일과 실제 연결

- root `package.json`, `package-lock.json`, `packages/*/package.json`: 7개 공개 패키지, private 예제 workspace, 내부 의존성을 1.4.3으로 동기화.
- `packages/*/CHANGELOG.md`: 기존 1.4.2 이하 기록은 그대로 두고 1.4.3 추가. coding-agent에는 overflow 복구 상한, admission cache, model refresh cache, opt-in timing 4개 PR의 실제 동작과 한계 기록. 다른 패키지는 lockstep 변경만 기록.
- `packages/book-to-skill/src/metadata.ts`: compiler identity 1.4.3. 기존 `scripts/sync-versions.js`를 통해 반영.
- `packages/coding-agent/npm-shrinkwrap.json`, 예제 lockfiles: 표준 npm 및 기존 결정적 생성기로 동기화.
- root `README.md`, `packages/coding-agent/README.md`, `.github/RELEASE_NOTES_v1.4.3.md`: 릴리스 링크, 설치 pin, 호환성, rollback과 기존 보안 한계 갱신.
- 연결 경로: 검증된 release commit -> `main`과 `v1.4.3` atomic push -> `.github/workflows/build-binaries.yml` -> 6종 바이너리/attestation -> CI의 `scripts/publish.mjs`로 npm 7종 배포 -> GitHub Release.
- 기존 release/version/shrinkwrap/README 생성기를 재사용했다. generated model catalog를 재생성하거나 외부 의존성을 바꾸지 않았다. 로컬 npm publish는 하지 않았다.

## Skills와 직접 검토

- `using-agent-skills`로 현재 작업을 분류하고 `pi-worktree`, `git-workflow-and-versioning`, `shipping-and-launch`, `adaptorch`, 검증 인터페이스 확인용 `adaptorch-synthesize`를 적용했다.
- 최종 자체 검토에는 `code-review-and-quality`, `deep-review`, `size-review`를 필요한 범위에서 적용했다. 실제 도구에 적합한 위임 인터페이스가 없어 root agent가 전부 직접 수행했다. UI/마케팅 스킬은 이번 배포와 무관하므로 로드하지 않았다.
- 30개 raw 파일에서 생성 lock 6개 제외 시 24개 파일/135줄 추가. 전부 한 lockstep release라 package별 또는 문서/코드 분할은 consistency gate를 깨는 가짜 경계다. 기능 PR 4개는 이미 분할 병합되어 있다.
- correctness/security/idiom/solution-fit 자체 검토: 새 외부 의존성/인증/권한/CI 로직 없음, 이력과 catalog 불변, 7종 source/npm/binary identity 연결 확인. 릴리스 신규 blocker 없음. 언어 서버의 nested clone Markdown 링크 경고는 실제 tracked target 및 repo 링크 검사로 반증했다. task-local Python SDK import는 OMK interpreter가 아닌 AdaptOrch venv에서 실행해 검증했다.

- 시작 미커밋 상태: porcelain 122개 항목, 확장한 실제 변경/untracked 파일 207개. HEAD, 원래 index, staged/binary patch 및 파일 archive를 배포 전에 백업했다.
- 깨끗한 별도 clone의 main에서만 배포 commit을 만들었다. 처음 `/tmp` clone은 native edit 쓰기 경계 밖이라 변경이 거부됐고, 허용 workspace 아래 task-owned clone으로 옮긴 후 편집했다. 보호 설정은 수정하지 않았다.

- 원본 staged 문서 3개의 patch는 byte-for-byte 보존했다. 다른 세션이 진행 중이던 `model-catalog-refresh.md`도 덮어쓰지 않았다.
- 최종 원본 main/origin/main은 위 release commit이며 ahead/behind 0/0, unmerged 경로 없음. 기존 미커밋 변경은 계속 로컬에 남아 있다.
